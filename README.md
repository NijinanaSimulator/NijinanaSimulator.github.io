# NijinanaSimulator

にじななの盤面をブラウザで操作する、手動シミュレータです。

**このツールは非公式で、ChatGPTを使って作成しています。使用は自己責任でお願いします。動作確認はWindows版のFirefoxとChromeのみで行っています。**

カードの効果、コストの支払い、構築条件、勝敗はプレイヤーが判断します。

## 1. カードを用意する

「カード登録」から画像カードや文字カードを手入力で追加することができます。

- **種別：** ライバー・イベント・ステージ・チャンネル
- **クラス：** 太陽・月・彗星・星
- **ライバーの設定：** 7色から複数の色と、パワーを設定できます。

## 2. デッキを用意する

1. 「デッキ編集」でカードごとの枚数を指定します。
2. チャンネルを専用欄で1枚選び、「デッキを決定」を押します。
3. 「n枚引く」または「n枚をランダムに引き直す」で手札を用意します。

チャンネルは山札に含めず、専用欄で指定します。

## 3. 盤面を操作する

### カードの基本操作

| 操作 | 動作 |
| --- | --- |
| クリック | カードを選択します。 |
| Shift＋クリック | 複数選択、またはそのカードの選択を解除します。 |
| ドラッグ／「選択」欄の移動ボタン | カードを別の場所へ移します。手札・フィールド・カラーラインなどでは、ドラッグして離した位置に並べられます。 |
| ダブルクリック | 盤面の山札・ログでは一覧を開きます。一覧内を含むその他のカードは内容を拡大します。カラーライン上のカラーカードは、その1枚の表裏を反転します。 |
| 選択欄 | 表裏・縦横・カウンター・メモ、ライバーのパワーを変更できます。 |

### 山札を見る・カードを移動する

盤面の山札・ログをダブルクリックすると、それぞれの一覧を開きます。一覧や「上から確認」からカードの内容を開いた場合は、画面上部の「一覧に戻る」または「上から確認に戻る」で元の画面へ戻れます。「閉じる」を押すと一覧・確認画面も終了します。

「山札の一覧」ではカードをドラッグして表示中の位置へ並べ替えられます。

- 移動先は、手札・ログ・セット・ステージ・山札・フィールドから選べます。
- 山札を選ぶと、枚数を指定して「n枚ドロー」「上からn枚確認」「上からn枚ログへ」を操作できます。

同じゾーンの元の位置へカードを戻した場合は、履歴・元に戻す・リプレイの操作数に加えません。

セット・ステージは各1枚までです。2枚目を置くと、前のカードをログへ送ります。

チャンネルの変更はデッキ編集で行います。手札などから直接置くことはできません。

### カラーカード

カラーカードは、選択欄から表裏の切り替えや同じ色のにじエリアへの移動ができます。表裏を変えてもカラーラインの順序は保持します。

自分の裏向きのカラーカードとセットカードは、選択欄で内容を確認できます。

### 相手の盤面・フェイズ・ターン

「相手の全フィールドを表示」で相手側の盤面も操作できます。

フェイズボタンはフェイズの表示を切り替えます。カード効果やドローは自動処理しません。ターンの「次へ」はターン数を進め、フェイズをスタートに戻します。

## 4. 盤面を整える

基本操作の「盤面操作」から、次の操作ができます。

- **自分のフィールドを全て縦向きにする：** 操作側のフィールド内を縦向きにします。
- **カラーカードの初期化：** 両者の7色をカラーラインへ裏向きで戻します。
- **カラーカードのシャッフル：** 両者のカラーラインにあるカラーカードをそれぞれ並べ替えます。表裏と、にじエリアにあるカードは保持します。
- **n枚をランダムに引き直す：** 通常カードを山札に集め、指定枚数を引き直します。カードの一時メモ・カウンター・パワー変更を解除します。
- **初期盤面に戻す：** 両側の山札とチャンネルをデッキ設定から作り直し、7色を裏向きで戻します。手札などを空にし、カウンターや一時的な変更をリセットして、ターン1から始めます。登録カード・デッキ設定・相手の表示設定は保持します。

「元に戻す」（Ctrl＋Z）で直前の操作を取り消し、「やり直す」（Ctrl＋X）で取り消した操作をやり直せます。

履歴欄の「履歴を初期化」は履歴だけを消し、盤面とデッキを保持します。

## 5. リプレイを記録・再生する

1. 盤面上部の「記録開始」を押します。
2. カード移動やフェイズ変更などを操作し、「記録終了」を押します。
3. 「再生」を押すと、記録した盤面を再現できます。

### 再生速度と操作

初期速度は1ステップ1.0秒です。「1ステップ」で0.5〜5秒に変更できます。一時停止、前後のステップへの移動、再生位置の指定にも対応します。

「操作に戻る」で再生前の作業中の盤面へ戻ります。

### カットイン

再生中は、フェイズが切り替わると移動先のフェイズ名を自動でカットイン表示します。

記録中の「テキストカットイン」で、好きな文章を1ステップ追加できます。記録後も「テキストを挿入」で追加し、文章の編集・削除ができます。文字数は300文字までで、改行も使えます。

### リプレイの保存

「リプレイ保存」でJSONファイルに保存し、「リプレイ読込」で開きます。新しく記録を始めると前の記録を置き換えるため、残すリプレイは先に保存してください。

1つの記録は200操作・100MBまでです。動画や音声の録画ではなく、操作の再現機能です。

## 6. 保存と復元

作業内容はブラウザ内に自動保存します。「JSON保存」でカード画像・登録カード・デッキ・盤面・リプレイをファイルにも保存できます。保存したファイルは「読込」から復元します。

別のブラウザや別の場所で本体を開くと、これまでの自動保存を利用できない場合があります。本体を移動・改名するときや別のPCで使うときは、先に「JSON保存」でデータを書き出してください。ブラウザの保存データを削除した場合も、JSONファイルから復元できます。

## 7. キー操作

| キー | 操作 |
| --- | --- |
| D | ドロー |
| R | 選択カードの向きを変更 |
| F | 選択カードの表裏を反転 |
| Ctrl＋Z | 元に戻す |
| Ctrl＋X | やり直す |
| Ctrl＋S | JSON保存 |

リプレイ再生画面では、スペースで再生・一時停止、左右キーで前後のステップへ移動します。文字を入力しているときやダイアログを開いているときは、盤面用のキー操作を止めます。

詳細はアプリ上部の「使い方」も参照してください。通信対戦・CPU対戦・カード効果の自動処理には対応していません。
